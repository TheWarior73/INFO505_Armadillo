◆ initPlanet()

Planet * initPlanet ( )

Initializes a planetwith random amounts of ressources, within playable parameters.

Playable parameters include :

  • Planet radius must be at least 100km
  • Population must be at least 2 to allow reproduction.
  • Water, Minerals and Wood at total must be at least the amount of starting population.

◆ runFullGame()

void runFullGame ( )

Runs the full game, turn by turn, until win condition or game over is reached.

This function will initialize everything to a playable state, before launching the game loop, once the loop stops it will handle memory deallocation as well.
